# Ginkgo App

## 运行

```bash
cd App && xcodegen && open Ginkgo.xcodeproj
```

选 iPad 模拟器或真机，Run。第一次用之前，在书库右上角的齿轮里选服务商（OpenAI / Anthropic / Gemini），填 API key，点「测试连接」。

逻辑层的单测在 `Packages/GinkgoKit`，直接 `swift test`。想连真实服务测一遍：`GINKGO_LIVE_AI=1 swift test --filter LiveProviderTests`（读取环境变量里的 key）。

## 验收清单

**书库**
- 右上角 ＋ 从「文件」导入 PDF，可以多选；也可以把 PDF 从别的 App 拖进来，或在别的 App 里用「共享 → Ginkgo」打开。
- 封面是第一页；按最近阅读排序；长按封面可以删除。
- 坏文件、带密码的 PDF 会提示原因。

**阅读**
- 连续上下滚动；旋转或分屏后页面自动适配宽度。
- 点一下页面空白处，隐藏或显示工具栏；下次打开回到上次读到的页。

**选中文字**（手指长按选择）
- 文字下方出现浮条：五种高亮颜色、翻译、解释、提问、复制。
- 点已有的高亮，可以换颜色、对它提问，或删除。

**AI 批注**
- 翻译、解释、提问的回答会逐字流出来。
- **横屏**：页面右边有页边栏，卡片和原文同一高度，细线连回原文。
- **竖屏**：页面右边缘只有一道色条，点色条或点高亮，卡片浮在原文下方。
- 顶部「阅读 / 回顾」：阅读模式下批注只留色条；回顾模式下全部展开。
- 卡片长按：复制回答、重新回答、收起、删除。没填 key 或 key 错误时，卡片上会说明原因，并给出「打开设置」。

**Pencil**（工具栏的笔按钮，或双击 Pencil 笔杆）
- 在一行字下面划一道：变成高亮，颜色在顶部浮条里选。
- 圈住一段字：选中这段，弹出同一个浮条。
- 在页面右侧的白边写字（横屏时也可以写在页边栏里）：手写识别成问题，挂到旁边那一行，AI 回答；卡片上保留你的笔迹。
- 其他笔迹原样保留在页面上，跟着滚动和缩放。
- 真机上只有 Pencil 能写，手指照常滚动；模拟器里鼠标也能写。

**批注列表与导出**（工具栏的列表按钮）
- 按页码列出全部批注，可以只看 AI 批注或只看高亮；点一条就跳过去。
- 右上角导出：Markdown 笔记，或带标准批注的 PDF（高亮、笔迹，AI 回答放在文字批注里），可以在别的阅读器里打开。

## 已知限制

- Pencil 的手感、划线和圈选的识别阈值，需要真机调。
- 竖屏回顾模式下，卡片会盖住下面几行字，点色条可以收起。
- 跨页选中的文字只记录第一页那部分。
- 还没有 iCloud 同步（第六阶段）。视觉参数集中在 `Ginkgo/Design/Theme.swift`；当前设计说明和浅深色截图见 [`docs/design/`](../docs/design/README.md)，等待审核。

## 模拟器调试参数

不用手动点也能截图检查（只在 Debug 构建里生效）：

- `-inMemoryStore YES`：不碰真实书库。
- `-seedSample YES -openFirst YES`：导入示例章节并打开。
- `-demoAnnotate YES`：自动加一条高亮和三条 AI 批注。AI 需要 key，可以用 `SIMCTL_CHILD_OPENAI_API_KEY` 传给模拟器。
- `-demoMode review`：以回顾模式打开。
- `-demoInk YES`：打开书写模式，并画一道划线、一个圈和页边一个问号。
- `-demoNotes YES`：打开批注列表。
- `-demoSelect "<文字>"`：选中这段文字。
