# Ginkgo App

## 运行

```bash
cd App && xcodegen && open Ginkgo.xcodeproj
```

选 iPad 模拟器或真机，Run。第一次用之前，在书库右上角的齿轮里选服务商（OpenAI / Anthropic / Gemini），填 API key，点「测试连接」。

逻辑层的单测在 `Packages/GinkgoKit`，直接 `swift test`。想连真实服务测一遍：`GINKGO_LIVE_AI=1 swift test --filter LiveProviderTests`（读取环境变量里的 key）。

## 验收清单

**书库**
- 右上角 ＋ 从「文件」导入 PDF，可以多选；也可以把 PDF 从别的 App 拖进来，或在别的 App 里用「共享 → Ginkgo」打开。
- 封面是第一页；按最近阅读排序；长按封面可以删除。
- 坏文件、带密码的 PDF 会提示原因。

**阅读**
- 连续上下滚动；旋转或分屏后页面自动适配宽度。
- 点一下页面空白处，隐藏或显示工具栏；下次打开回到上次读到的页。

**选中文字**（手指长按选择）
- 文字下方出现浮条：五种高亮颜色、翻译、解释、提问、复制。
- 点已有的高亮，可以换颜色、对它提问，或删除。

**AI 批注**
- 翻译、解释、提问的回答会逐字流出来。
- 书页占满宽度。每条批注在页面右边缘是一个小贴签（颜色加类型图标）；点贴签或点高亮，卡片浮在原文旁边，点空白处收起。
- 回答很长时，卡片只显示前几行，点「展开全文」：横屏从右侧推出侧边栏，竖屏在右侧浮起面板。
- **横屏回顾模式**：右侧边栏常驻，卡片和原文同一高度，细线连回原文。
- 顶部「阅读 / 回顾」：阅读模式下批注只留色条；回顾模式下全部展开。
- 卡片长按：复制回答、重新回答、收起、删除。没填 key 或 key 错误时，卡片上会说明原因，并给出「打开设置」。

**Pencil 工具**（页面顶部常驻的工具栏，不用切换模式）
- Pencil 落笔就是当前工具，手指照常滚动、长按选字。再点一次当前工具可以放下它，这时 Pencil 也用来选字。第一次打开时工具栏下面有一句提示。
- **荧光笔**：落笔后高亮跟着文字实时延伸，起止都吸附到完整的单词，抬笔就是最终效果。工具栏里可以切到「自由涂抹」：保留手绘笔迹，笔尖在终点停半秒再抬起会拉直。
- **划线**：直线或波浪线（工具栏里切换），在文字下方划，标记同样实时跟着那一行走，贴在基线下方。
- **圈选**：圈住一段字，弹出翻译、解释、提问的浮条；圈的笔迹随后消失。
- **钢笔**：自由书写，颜色可选；在页面右侧白边写字（侧边栏打开时也可以写在侧边栏里），会识别成问题挂到旁边那一行，由 AI 回答，卡片上保留笔迹。
- **橡皮**：擦掉笔迹；划过高亮或划线时把它删掉（带 AI 回答的批注不会被擦掉，要从卡片上删）。
- **双击笔杆**：跟随系统设置（切到橡皮、切回上一个工具，或打开工具面板）。
- **捏合**（Apple Pencil Pro）：在笔尖周围弹出扇形面板，朝屏幕中间展开：内圈是工具，外圈是当前工具的线型和颜色。选了颜色或点空白处就收起。
- **悬停**（支持悬停的 iPad）：笔尖靠近屏幕时，显示当前工具颜色的小圆圈。
- **用手指画**（设置 → 手势）：手指也能用工具时，单指直接用当前工具，双指滚动，双指捏合缩放；放下工具才能用手指选字。默认跟随系统「仅用 Apple Pencil 绘图」：没用过 Pencil 的 iPad 上手指能画；也可以固定成「手指也能用工具」或「只用 Apple Pencil」。
- 工具、颜色、划线样式、手指开关都会记住。模拟器里没有 Pencil，选了工具后鼠标就是 Pencil，放下工具才能选字。

**撤销与重做**
- 工具栏最左边是撤销、重做两个按钮。
- 系统手势：三指左滑撤销，三指右滑重做，三指轻点弹出编辑栏；接键盘时用 ⌘Z 和 ⇧⌘Z。
- 拿着 Pencil 工具时，双指轻点页面也能撤销（可以在设置的「手势」里关掉）。
- 能撤销的操作：高亮、划线、AI 批注的新建和删除，换颜色，笔迹（包括橡皮擦掉的）。撤销删除时，AI 回答原样回来，不重新请求。

**批注列表与导出**（工具栏的列表按钮）
- 按页码列出全部批注，可以只看 AI 批注或只看高亮；点一条就跳过去。
- 右上角导出：Markdown 笔记，或带标准批注的 PDF（高亮、笔迹，AI 回答放在文字批注里），可以在别的阅读器里打开。
- 同一个菜单里有「清除全部批注…」：恢复到导入时的样子（PDF 原文件从不改动）。弹窗列出要删的内容，可以先导出笔记再清除；书没关之前，撤销一步就能整批恢复。书库里长按封面也能清除，但那里不能撤销。

## 已知限制

- Pencil 的手感、吸附的阈值，以及"工具状态下手指仍能选字"，需要真机验证。
- 浮起的卡片会盖住几行字，点贴签或空白处可以收起。
- 横屏书页占满宽度后字很大，一屏的行数少；可以双指捏合缩小。
- 跨页选中的文字只记录第一页那部分。
- 还没有 iCloud 同步（第六阶段）。视觉参数集中在 `Ginkgo/Design/Theme.swift`；当前设计说明和浅深色截图见 [`docs/design/`](../docs/design/README.md)，等待审核。

## 模拟器调试参数

不用手动点也能截图检查（只在 Debug 构建里生效）：

- `-inMemoryStore YES`：不碰真实书库。
- `-seedSample YES -openFirst YES`：导入示例章节并打开。
- `-demoAnnotate YES`：自动加一条高亮和三条 AI 批注。AI 需要 key，可以用 `SIMCTL_CHILD_OPENAI_API_KEY` 传给模拟器。
- `-demoMode review`：以回顾模式打开。
- `-demoInk YES`：用划线、圈选、荧光笔和钢笔各画一笔（页边一个问号），检查识别结果。
- `-demoClear YES`：演示结束后清除全部批注。
- `-demoScratch YES`：打开草稿纸。
- `-visualFixture study`（配合 `-inMemoryStore YES -demoPeek YES`）：摆出词卡、重点表达和一轮追问，不调用 AI。
- `-demoUndo N`、`-demoRedo N`：演示结束后撤销 N 步，再重做 N 步。
- `-demoTool <highlighter|underline|lasso|pen|eraser>`：选中工具；`-demoPalette YES`：打开捏合后的工具面板。
- `-demoNotes YES`：打开批注列表。
- `-demoPeek YES`：打开所有批注的浮起卡片；`-demoExpand YES`：展开第一条批注。
- `-demoSelect "<文字>"`：选中这段文字。
